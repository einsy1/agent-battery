# agent battery 2.3.0

新增 Claude Code 套餐用量：五小时额度、每周额度、重置时间，以及模型每周额度（如 Opus）。

## 新增与调整

- **Claude 服务页**：顶部切换为 Codex / Claude / Antigravity / DeepSeek。选中 Claude 时，各布局使用与 Codex 相同的卡片、进度条和重置时间显示。
- **HUD 同屏**：全景 HUD 同时显示 Codex、Claude Code、Antigravity。
- **菜单栏**：显示范围新增「仅 Claude Code」。
- **连接与设置**：未登录时面板提供「连接 Claude Code（官方登录）」；设置 → 高级可指定 claude 程序。
- **极客双色**：Claude Code 使用陶土橙，低额度仍为琥珀色。

## 隐私与边界

- 通过 Claude Code 自身的 `get_usage` 查询，不发送对话、不调用模型、不保存会话；本应用不读取钥匙串或凭证文件。
- API Key / Bedrock / Vertex 会话没有套餐额度，会提示连接订阅账户。
- 成功读取路径通过 mock 测试与样例渲染验证；开发机上的 Claude Code CLI 未单独登录，真实检查返回「需要连接」。
